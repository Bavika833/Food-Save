# FoodSave — Campus Food Waste Reduction

React + Express + MongoDB starter for discounted surplus meal listings, quantity reservations, pickup slots, and savings tracking. The server includes sample canteen listings for the demo.

Run `npm install`, optionally copy `.env.example` to `.env` and configure MongoDB, then run `npm run dev`. Build with `npm run build` and run with `npm start`.

Sample inventory and reservations reset when the server restarts. A real deployment should connect canteen accounts, allergen/food-safety data, payment, pickup verification, and durable inventory transactions.
